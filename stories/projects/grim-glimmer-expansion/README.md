# Grim & Glimmer Feature Expansion

Dedicated Storybook project group for the Player Experience, Progression & Puzzle Assistance expansion (gothic-cozy-puzzles#68). Keep new previews here while they are planned and reviewed, separate from the approved V4 baseline.

GameMenu consumes the supported `createGameMenuContent`, existing floating overlay and consolidated header. Fixture actions are explicitly local; they never pretend to open a real app puzzle. Future expansion previews should use the same project group and public APIs.
